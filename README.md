# Análise Estatística de Dados de E-commerce

## Sobre o projeto

Este projeto apresenta uma análise exploratória e estatística de um conjunto de dados de e-commerce utilizando Python.

O objetivo é identificar padrões, distribuições e relações entre características dos produtos, como preço, avaliações, descontos, marcas, gênero e faixas de vendas.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Análises realizadas

O projeto apresenta os seguintes tipos de visualização:

- Histograma
- Gráfico de dispersão
- Mapa de calor
- Gráfico de barras
- Gráfico de pizza
- Gráfico de densidade
- Gráfico de regressão

## Principais resultados

Um dos principais resultados encontrados foi a forte correlação positiva entre o número de avaliações e a faixa de vendas dos produtos, apresentando coeficiente de correlação de 0,91.

Também foram analisadas a distribuição dos preços, a participação dos produtos por gênero e a presença das principais marcas no conjunto de dados.
